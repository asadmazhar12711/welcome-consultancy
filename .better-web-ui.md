# Welcome Consultancy — Design Context

## Audience
Indian exporters, importers, MSME manufacturers, and compliance managers seeking DGFT / EXIM advisory.

## Use cases
Discover services, estimate incentives (RoDTEP/EPCG), generate document checklists, book consultations, inquire with service pre-fill.

## Brand personality
Authoritative, precise, calm confidence. Feels like a senior trade counsel — not a startup SaaS template, not a 2000s brochure site.

## Visual system
- **Accent locked:** Deep Navy `#0F172A`, Warm Gold `#D4AF37`
- **Surfaces:** Cool chalk `#F3F5F7` / mist `#E8EEF4` (never cream+terracotta cluster)
- **Type:** Display `Newsreader` (editorial serif) + Body `Manrope` (no Inter/Roboto/Arial)
- **Direction:** Institutional editorial — one composition hero, floating island nav, asymmetric service rows (not equal card grids), gold used sparingly as the single accent moment
- **Motion:** Soft fade-up / island morph; cubic-bezier spring; transform+opacity only
- **Density:** Airy marketing (generous section padding), compact admin

## Dial defaults
VARIANCE: 6 | MOTION: 5 | DENSITY: 3

## Anti-patterns (hard ban)
Purple gradients, Inter defaults, equal 3-card feature strips in hero, rainbow badges, glassmorphism on every surface, inset hero media cards, emoji decoration.
