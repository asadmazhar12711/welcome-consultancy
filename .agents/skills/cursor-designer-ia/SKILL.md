# Cursor Designer & Information Architecture Skill

Use this skill when designing or restructuring navigation, service catalogs, conversion funnels, or multi-step forms.

## 1. Calm Design & Progressive Disclosure
- Don't overwhelm users with 50 options on screen at once.
- Use tabs, accordion drawers, and expandable modals to reveal advanced settings only when needed.
- Keep primary navigation clean (4–6 core links max) and use structured Bento dropdowns for complex sub-services.

## 2. High-Converting UX Copywriting
- Action-oriented CTAs: Use `Calculate Your RoDTEP Incentive ->` or `Book Advisory Slot (Live)` instead of generic `Submit` or `Click Here`.
- Financial Value Framing: Always show tangible impact metrics (`e.g., ₹500Cr+ Export Incentives Claimed`, `16 DGFT Services`, `500+ Active Exporters`).

## 3. Product-Led Interactive Architecture
- Allow users to test calculators and preview their export benefits directly on the landing page.
- Make the path from "testing calculation" to "booking consultation" seamless via sticky WhatsApp CTAs (`+91 98671 73397`) and inline booking modals.
