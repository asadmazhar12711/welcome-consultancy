# Visual QA Testing Skill

Use this skill whenever building or modifying UI components, headers, cards, or admin tables.

## Steps

1. Launch dev server and navigate to target route (e.g. `/`, `/services/epcg-license`, `/admin`).
2. Verify visual appearance against Deep Navy (`#0F172A`) & Warm Gold (`#D4AF37`) palette.
3. Check browser console for errors or warnings.
4. Verify typography contrast, button hover states, and responsive layout behavior.
