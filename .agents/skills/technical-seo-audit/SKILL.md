# Technical SEO, AIO & GEO Audit Skill

Use this skill when creating or validating pages for Welcome Consultancy.

## Checklist

- [ ] **Mobile-First Priority**: Responsive mobile testing, sticky WhatsApp (`+91 98671 73397`) and Phone CTAs.
- [ ] **Semantic HTML**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- [ ] **Single H1**: Exactly one `<h1>` per page.
- [ ] **GEO Question Optimization**: Direct answer summaries in introductory paragraphs.
- [ ] **Dynamic Metadata & JSON-LD**: Next.js Metadata API, `LocalBusiness`, `ProfessionalService`, `Service`, `FAQPage`, `BreadcrumbList`.
- [ ] **AI Agent Standard**: Valid `public/llms.txt` file present.
- [ ] **Form Pre-filling**: Service cards pass service parameter to contact form for auto-prefilling.
- [ ] **Core Web Vitals**: Sub-2.5s LCP, sub-200ms INP, sub-0.1 CLS.
