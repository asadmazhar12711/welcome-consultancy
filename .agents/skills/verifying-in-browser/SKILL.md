# Verifying in Browser Skill

Use this skill when verifying UI features, interactive calculators, slot schedulers, or form submissions.

## Workflow

1. Start dev server using `npm run dev` or `wrangler pages dev`.
2. Verify local dev server URL (e.g. `http://localhost:3000`).
3. Check browser console logs for JavaScript runtime errors or broken assets.
4. Verify responsiveness across desktop and mobile viewports.
