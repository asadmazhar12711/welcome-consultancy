# EXIM Calculators & Slot Scheduler Skill

Use this skill when building or editing interactive widgets and appointment schedulers.

## 1. RoDTEP & Duty Drawback Export Incentive Calculator
- Input: Annual FOB Turnover ($ or ₹) and Export Sector (Textiles, Engineering, Chemicals, Agriculture, Electronics).
- Output: Estimated incentive percentage (0.5% - 4.3%) and total annual cashback estimation.
- Lead Capture: Prompt to email/WhatsApp detailed breakdown to user's mobile number.

## 2. EPCG Duty Savings Estimator
- Input: Capital Goods Import Value ($ or ₹).
- Output: Estimated Customs Duty Exemption (approx 28.5%) and Export Obligation requirement (6x duty saved over 6 years).
- Lead Capture: Instant callback request trigger.

## 3. Custom Document Checklist Generator
- Dynamic selector based on EXIM service (EPCG, IEC, Advance License, Star Export House).
- Generates precise document requirements checklist.

## 4. Live Consultation Booking Calendar
- Dynamic UI allowing user to pick date, select available time slot, input name & mobile number.
- Syncs booking directly with Admin CMS slot table.
