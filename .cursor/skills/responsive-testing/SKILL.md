# Responsive Testing Skill

Use this skill to audit responsive layouts across all 16 service pages and homepage hero sections.

## Guidelines

- Desktop Viewport: `1240px` and above (Mega Menu active, multi-column footer).
- Tablet Viewport: `768px - 1024px` (Fluid 2-column grids).
- Mobile Viewport: `375px - 640px` (Single column, sticky call/WhatsApp floating action buttons active, touch-friendly tap targets min 44px).
