# Auto Type Checking Skill

Use this skill after modifying TypeScript components, API routes, or database query handlers.

## Workflow

1. Run `npx tsc --noEmit` or type checker command.
2. Resolve any missing property types, parameter mismatches, or null dereferences before concluding task.
